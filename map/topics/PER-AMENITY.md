# PER-AMENITY - Amenities, compensating differentials, benefits

**Status:** taught (Sets 3 and 6; there is no dedicated lecture topic) · **Exam weight:** in **1/4** finals/resits (R25 Q6 = 6 pts) · 3 F/R sub-Qs · **2.9% of a typical exam** (split) · **Priority B** (a one-off block, but its tutorial twin is near-identical, so it is cheap points)

## How the exam asks it

Template **T15** (amenity variant). The logic is efficiency vs rents.

| Exam Q | Type | Result |
|---|---|---|
| [R25 6a](<../../Past exams/Resits/2025-07 Resit (with solutions).pdf>) | Reasoning (2) | A social-media ban is efficient iff the firm's production gain X > the worker's utility loss V (ignore third parties) |
| [R25 6b](<../../Past exams/Resits/2025-07 Resit (with solutions).pdf>) | Reasoning (2) | A high binding minimum wage leaves the PC slack, so the firm ignores V and bans |
| [R25 6c](<../../Past exams/Resits/2025-07 Resit (with solutions).pdf>) | Reasoning (2) | The wage is set at the PC, so the firm pays for V through the wage (internalises it) and allows iff V > X |

**Steps:**
1. Efficiency: compare the worker's money-equivalent gain with the firm's cost; transfers do not count.
2. Ask whether the PC binds. If yes, the wage adjusts by V and the firm internalises it. If the worker earns rents, the firm ignores V.
3. Conclude for each regime.

**Pitfalls:** state explicitly which constraint binds; the answer flips with it.
