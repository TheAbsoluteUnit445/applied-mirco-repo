# Applied Microeconomics (FEB12001X) - exam manual

Course material, past exams and an **exam map** for Applied Microeconomics at Erasmus School of Economics, 2026/27: Public Economics (Delfgaauw) and Personnel Economics (Dur). **Final exam: Fri 23 Oct 2026, 09:30-12:30.**

## Start here

### October lecture study pack — start here for the five assigned modules

**[Open the study pack and coverage table](<study-packs/Upcoming lecture block/index.md>)** for optimal taxation (R&G 16), collective decision-making (R&G 6), discrimination (Kuhn 16), workplace competition (Kuhn 20–23), and teams (Kuhn 24–27). Each module includes theory, derivations, attempt-first practice, and worked solutions. Companion lectures contain 80 slides and nine interactive graphs.

**On your PC:** download or clone this repository, keeping its folder structure. Open `study-packs/Upcoming lecture block/index.html` for the readable modules and `study-packs/Upcoming lecture block/lectures.html` for the lecture launcher. Choose **OPEN OFFLINE.html** for each deck when opening from disk. GitHub displays the Markdown notes; the interactive HTML runs locally.

For a local browser preview with source links, run this from the repository folder:

```powershell
node '.\study-packs\Upcoming lecture block\serve.mjs'
```

Then open <http://127.0.0.1:3057/study-packs/Upcoming%20lecture%20block/index.html>. See [full opening and rebuilding instructions](<study-packs/Upcoming lecture block/README.md>).
