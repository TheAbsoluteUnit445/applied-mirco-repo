# PUB-PG-SAM: Efficient provision of public goods, Samuelson rule (ΣMRS = MRT)

**Status:** taught (W1) | **Exam weight:** 3 of 4 finals/resits (F24, F25, R26) plus both midterms, so 5 of 6 papers. Split weight 10.5% summed, **about 2.6% per exam** | **Priority: A**

Exam page numbers (p.) are PDF pages of the solutions file. Templates: see [exams-tagged.md](<../_work/exams-tagged.md>) §3.

## 1. How the exam asks it
Template: **T1** (public good: Samuelson + Nash + add-on), steps 1-2. Two setups recur:
- quasi-linear U_i = a_iQ − ½Q² with price c;
- MRS-based (MRS_i = x_i/G, or 8/√y).

| Exam Q | Type, pts | Solution steps |
|---|---|---|
| [M23 1b](<../../Past exams/Midterms/2023 Midterm (with solutions).pdf>) p.2 | Numerical, 1 | 1) MRS_i = x_i/(G_A+G_B). 2) Write MRS_A + MRS_B = p_G (MRT). 3) Substitute budgets x_A + x_B = 2y − p_G·G. 4) Solve G = y/p_G. |
| [M25 1a](<../../Past exams/Midterms/2025 Midterm (with solutions).pdf>) p.1 | Numerical, 1 | 1) MU_i = a_i − Q. 2) MU_A + MU_B = c. 3) Solve Q = (a+b−c)/2. |
| [F24 5a](<../../Past exams/Finals/2024-10 Final (with solutions).pdf>) p.7 | Numerical, 1 | 1) Sum the three MUs (α, b, d). 2) Set equal to MC = λQ. 3) Q* = (α+b+d)/λ. |
| [F25 7c](<../../Past exams/Finals/2025-10 Final (with solutions).pdf>) p.13 | Numerical, 2 | 1) The good is public, so y is common. 2) MRS_C + MRS_D = MRT. 3) Solve y = 9. (Contrast with 7b, where MRS_i = MRT per person.) |
| [R26 1a](<../../Past exams/Resits/2026-07 Resit (with solutions).pdf>) p.2 | Numerical, 2 | 1 pt for the condition MU_A + MU_B = MC, 1 pt for the MUs and the solution q = (a+b−c)/2. A near-copy of M25 1a. |

**Pitfalls:**
- Writing ΣMRS = MRT **without solving** = 0 (M23 1b).
- Any route that doesn't use Samuelson is "wrong" (M23).
- Check the corner: a person's MU can hit 0 (kinked MB, Ex 1.2). Sum only over the range where each MB > 0.
