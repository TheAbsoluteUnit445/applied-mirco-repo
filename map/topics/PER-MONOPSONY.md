# PER-MONOPSONY - Monopsony, labour supply elasticity, markdown, non-profits and volunteers

**Status:** taught (lecture 6, Set 6) · **Exam weight:** in **3/4** finals/resits (F24, F25, R26) · 8 F/R sub-Qs · **7.5% of a typical exam** (split; #2 overall) · **Priority A**

## How the exam asks it

Template **T11**. It comes in two versions: **for-profit** (F25) and **non-profit with a budget** (F24, R26). It has been recycled from F24 Q1 to R26 Q9.

| Exam Q | Type | Content / result |
|---|---|---|
| [F24 1a](<../../Past exams/Finals/2024-10 Final (with solutions).pdf>) | Model setup | non-profit budget B = wN(w) + pZ |
| [F24 1b](<../../Past exams/Finals/2024-10 Final (with solutions).pdf>) | Verbal (max 2 sentences) | N(0) > 0: some people work for a zero wage, so they are volunteers |
| [F24 1c](<../../Past exams/Finals/2024-10 Final (with solutions).pdf>) | Derivation + interpretation | FOC N′(w)Q − (1/p)[N + wN′] = 0. The extra hires add output, but the bigger wage bill leaves less budget for market goods |
| [F25 1a](<../../Past exams/Finals/2025-10 Final (with solutions).pdf>) | Verbal (max 2 sentences) | perfect competition: N′ = +∞ (a small wage cut and all workers quit) |
| [F25 1b](<../../Past exams/Finals/2025-10 Final (with solutions).pdf>) | Interpretation | MB of a raise = N′(Q − W); MC = N (every current worker gets the raise) |
| [F25 1c](<../../Past exams/Finals/2025-10 Final (with solutions).pdf>) | Numerical | W = ηQ/(1+η) = 4000 at η = 2, Q = 6000; profit per worker 2000 |
| [R26 9a](<../../Past exams/Resits/2026-07 Resit (with solutions).pdf>) | Derivation | MC of a €1 raise = d(WN(W))/dW = N + WN′ |
| [R26 9b](<../../Past exams/Resits/2026-07 Resit (with solutions).pdf>) | Verbal | monopsony power iff N′ < ∞ |

**Steps:**
1. Write the objective. For-profit: Π = (Q − W)N(W). Non-profit: output with Z = (B − WN)/p substituted in.
2. Differentiate in W.
3. Label each FOC term in economic words: the marginal benefit comes from extra hires, the marginal cost from the raise paid to all existing workers.
4. For the markdown, multiply the FOC by W/N and use η = (W/N)N′, which gives W = ηQ/(1+η).
5. Limits: η → ∞ means competition (W = Q). η small means a big markdown.

**Pitfalls:** 1 pt per FOC term, *explained in economic words*, not "math in words" (F24 1c, F25 1b). F25 1a needs both the value (∞) and the reason.

- **Covered:** the for-profit markdown (T6 6.2).
