# PER-SEL-SCREEN - Recruitment, testing, self-selection, screening, signalling/certificates

**Status:** taught (lecture 5, Set 5) · **Exam weight:** in **3/4** finals/resits (F24, F25, R26) · 6 F/R sub-Qs · **4.5% of a typical exam** (split) · **Priority A**

## How the exam asks it

Template **T13**.

| Exam Q | Type | Content / result |
|---|---|---|
| [F24 4](<../../Past exams/Finals/2024-10 Final (with solutions).pdf>) | Derive conditions | Probation with detection probability p. Unskilled: W1 + (1−p)W2 + pW_u < 2W_u. Skilled: W1 + W2 ≥ 2W_s |
| [F25 2a](<../../Past exams/Finals/2025-10 Final (with solutions).pdf>) | Numerical | Symmetric ignorance + zero profit: everyone earns the mean (50) |
| [F25 2b](<../../Past exams/Finals/2025-10 Final (with solutions).pdf>) | Reasoning + iteration | Free certificates lead to full unravelling: 50 → 35 → 27.5 → ... |
| [F25 2c](<../../Past exams/Finals/2025-10 Final (with solutions).pdf>) | Numerical (3) | Costly certificate. The marginal type is indifferent: q* − 20 = (q* + 20)/2, so q ≥ 60 certify and the uncertified earn 40 |
| [R26 7d](<../../Past exams/Resits/2026-07 Resit (with solutions).pdf>) | Reasoning | A wage between the motivated type's reservation wage U_alt − γ²/(4θ) and U_alt attracts only the motivated, so unobservable type is no problem |
| [R26 8a](<../../Past exams/Resits/2026-07 Resit (with solutions).pdf>) | Verbal | Performance pay also attracts productive workers (sorting) |

**Steps:**
1. Write one participation constraint per type over the whole contract (both periods).
2. Require desired type ≥ outside option and undesired type < outside option.
3. With asymmetric information and zero profit, the wage = the expected productivity of the pool.
4. A free verifiable signal unravels the pool from the top.
5. A costly signal: find the marginal type, who is indifferent between certifying and being paid the uncertified mean, and solve for the cutoff.

**Pitfalls:** for probation, include the detected-and-fired branch (pW_u). Iterate the unravelling at least 2-3 steps before concluding.
