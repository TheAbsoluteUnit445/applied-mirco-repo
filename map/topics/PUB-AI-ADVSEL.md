## 1. How the exam asks it
Template: **T8** (lemons). The same logic appears in Personnel as pooling/unravelling (F25 Q2), so it pays twice.

| Exam Q | Type, pts | Solution steps |
|---|---|---|
| [R25 2a](<../../Past exams/Resits/2025-07 Resit (with solutions).pdf>) p.4 | Proof, 2 | 1) Buyers' maximum WTP for a random car = λB_H + (1−λ)B_L. 2) Adverse selection (good cars withdrawn) iff that is < S_H (definition: 1 pt). 3) Rearrange to B_H < 300 + 200/λ (algebra: 1 pt). |
| [R25 2b](<../../Past exams/Resits/2025-07 Resit (with solutions).pdf>) p.4 | Verbal ≤3 sent., 2 | A higher share of good cars raises the expected quality, so expected WTP rises, so a lower B_H already suffices to keep the good sellers in. |
| [R25 2c](<../../Past exams/Resits/2025-07 Resit (with solutions).pdf>) p.4 | Verbal ≤2 sent., 2 | Only lemons trade, so the price lies between the lemon seller's reservation price and the buyer's value: S_L ≤ p ≤ B_L (100-300). |

**Pitfalls:**
- State the *definition* explicitly (expected WTP < high-quality seller's reservation price); that is half the proof points.
- The price range uses the **lemon** values only.
