# PUB-EXT-GAME: Externalities as strategic games (Nash vs efficient cell)

**Status:** taught (W2) | **Exam weight:** 0 of 4 finals/resits. Midterm M23 only (1 pt, 10% of that midterm) | **Priority: C** (skim; the *idea* "the individual ignores the cost to others" is reused everywhere)

Exam page numbers (p.) are PDF pages of the solutions file. Templates: see [exams-tagged.md](<../_work/exams-tagged.md>) §3.

## 1. How the exam asks it
There is no F/R template. It appeared once, as a midterm 2×2 game.

| Exam Q | Type, pts | Solution steps |
|---|---|---|
| [M23 2a](<../../Past exams/Midterms/2023 Midterm (with solutions).pdf>) p.5 | Verbal + 2×2 table, 1 | 1) Find each player's dominant strategy, which gives the Nash cell (Inside, Fire). 2) Find the cell with the maximum *sum* of payoffs (Outside, No fire). 3) Explain in at most 4 sentences: a negative externality that Scott ignores. |

**Pitfalls:** you need the correct NE **and** the correct efficient cell **and** the named failure. If either cell is wrong you get 0.
