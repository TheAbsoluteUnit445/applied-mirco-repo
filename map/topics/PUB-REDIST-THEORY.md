## 1. How the exam asks it
Template: **T4** step 5 (redistribution with √-utility, leaky bucket).

| Exam Q | Type, pts | Solution steps |
|---|---|---|
| [F25 6a](<../../Past exams/Finals/2025-10 Final (with solutions).pdf>) p.11 | Numerical, 2 | 1) max SW = w·U_A + U_B (√-type utilities as given) s.t. I_A + I_B = Y (Lagrange, or substitute I_B = Y − I_A). 2) FOC: w·MU_A = MU_B. 3) Solve I_A = w²/(w²+β²)·Y. (Shared with SWF.) |
| [F25 6b](<../../Past exams/Finals/2025-10 Final (with solutions).pdf>) p.11 | Verbal ≤2 sent., 2 | A higher weight means society values A's utility more, so an extra euro to A is worth more socially, so more is redistributed to A. |
| [F25 6c](<../../Past exams/Finals/2025-10 Final (with solutions).pdf>) p.11 | Verbal, 2 | Leaky bucket: each euro taken from the rich delivers less than a euro to the poor, which raises the cost of redistributing. The optimum redistributes *less*, so Berta (the recipient) gets less. This is the equity-efficiency trade-off. |
| [R26 4c](<../../Past exams/Resits/2026-07 Resit (with solutions).pdf>) p.10 | Verbal ≤2 sent., 1 | Normative (distribution/ethics) reason not to mandate search even if efficient. Efficiency argument = 0. (Shared with POSNORM.) |

**Pitfalls:**
- Write the Lagrangian/FOC; a bare result gets 0 (rule 6).
- 6b-6c want the economic channel, not "because w is in the numerator".
- 6c: the answer is a *direction* (less) plus the reason.
