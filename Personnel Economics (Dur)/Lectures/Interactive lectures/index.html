How to use

Use the visible Next/Back controls or arrow keys. Drag a gold graph dot or use a labeled slider; Reset restores the example. Press P or choose Present for presenter notes and an audience window. Each lecture is self-paced and silent.

Presenter mode shares slide position. Interactive graph changes are local to the window where you make them; for teaching with live graphs, share that window. Notes distinguish textbook results, illustrative extensions, and the actual exam question.
