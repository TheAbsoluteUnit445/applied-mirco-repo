# Topic IDs (the backbone)

Every exam question, tutorial exercise, lecture, book section and book exercise is tagged with one or more IDs from this list. The gap analysis is simply: **IDs that the exams ask about, but that no tutorial exercise trains.**

Rules:
- Use the IDs as written. If something truly doesn't fit, add a new ID here (same prefix style) with a one-line description and the source of truth, rather than inventing one ad hoc in another file.
- **Source of truth = the textbook** (Rosen & Gayer 10th ed. for Public, Kuhn for Personnel). Lectures and tutorials select from it; the book has the full derivations and examples.
- Status column: `taught` = lecture + exercise set released; `upcoming` = on the syllabus, not yet lectured/released (as of 5 Oct 2026).
