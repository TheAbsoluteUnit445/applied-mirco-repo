# PER-PA-PRINC - The principal's problem: optimal bonus b, participation constraint, base salary

**Status:** taught (lecture 1, Set 1-2) · **Exam weight:** in **2/4** finals/resits (R25, R26) + both midterms (M23, M25; 70% of midterm points summed) · 5 F/R sub-Qs · **3.1% of a typical exam** (split; steps 2-4 of every T10 block) · **Priority A**

## How the exam asks it

Template **T10, steps 2-5**. It is recycled heavily: M23 Q3 → R25 Q4, R26 6d. M25 Q3 → R25 Q4.

| Exam Q | Type | Result |
|---|---|---|
| [M23 3a](<../../Past exams/Midterms/2023 Midterm (with solutions).pdf>) | Numerical + explain steps | b = P/2 − K (no base salary) |
| [M23 3b](<../../Past exams/Midterms/2023 Midterm (with solutions).pdf>) | Verbal | b falls in K: the bonus is also paid on the K units that effort does not cause |
| [M23 3c](<../../Past exams/Midterms/2023 Midterm (with solutions).pdf>) | Derivation | binding PC: a = −Kb − b²/4 |
| [M25 3b](<../../Past exams/Midterms/2025 Midterm (with solutions).pdf>) | Numerical | b = (p + β)/2 |
| [R25 4b](<../../Past exams/Resits/2025-07 Resit (with solutions).pdf>) | Derivation | lowest base salary from U ≥ V |
| [R25 4c](<../../Past exams/Resits/2025-07 Resit (with solutions).pdf>) | Numerical (3 pts) | two-part contract: b = p |
| [R26 6c](<../../Past exams/Resits/2026-07 Resit (with solutions).pdf>) | Numerical (4 pts) | b = (p − γ)/2 |
| [R26 6d](<../../Past exams/Resits/2026-07 Resit (with solutions).pdf>) | Verbal (max 3 sentences) | why b falls in γ (the same logic as M23 3b) |
| [R26 7b](<../../Past exams/Resits/2026-07 Resit (with solutions).pdf>) | Numerical | PC wage U_alt − γ²/(4θ) |

**Steps:**
1. Agent FOC gives e(b).
2. If there is a base salary, set the PC to bind, U(e(b), a, b) = U_alt, which gives a(b).
3. Write profit Π = pq(e) − a − b·q(e) and substitute e(b) (and a(b)).
4. Take the FOC in b and solve.
5. Interpret. With no base salary, b = (p ± shift)/2. With a base salary, b = p ("sell the job"), because a extracts the rent.

**Pitfalls:** "just writing b = p without a derivation does not result in any point" (R25 4c). Points come per step: profit 1, substitution 1, FOC 1, solve 1. A correct approach with an arithmetic slip still gets full marks (M23 3c).
